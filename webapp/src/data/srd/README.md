# SRD 5e catalogue (English source)

Generated data from the D&D 5e System Reference Document 2014, fetched from
https://www.dnd5eapi.co. Content is licensed CC-BY-4.0 (Wizards of the Coast SRD 5.1).
Italian translations are added next to each `en` field by a later step.

Regenerate (from Windows): `uv run python scripts/build_srd_catalog.py`

Do not edit the JSON by hand; curated magic-item mechanics and racial roll notes
live in the script (`MECHANICS`, `ROLL_NOTES`).
